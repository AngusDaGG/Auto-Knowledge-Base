# Contributing

Open an issue for substantial behavior changes; small fixes can go directly to a Draft PR. Keep changes focused and run the relevant README test commands. Explain observable behavior, validation and remaining limits.

Never include real user workspaces, media, API keys, browser data or private repository history. Use synthetic fixtures. Preserve engine platform-denial boundaries and knowledge-only publication. Do not make a passing test by skipping a failing safety check.

Runtime dependency changes, external model integrations and security/publication policy changes need maintainer review. CI runs without model keys, platform credentials, downloads or deployment permissions. There is no CD target or auto-updater.
